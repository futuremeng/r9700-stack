Three things that bite when pasting: LiteLLM and the OpenAI SDK want the base
        with /v1 (curl wants it without, as the block above shows), the model
        string is openai/<served name>, and these launches run a reasoning parser —
        message.content can come back None with everything spent on
        message.reasoning_content, because reasoning counts against max_tokens. The
        path under “Weights live at” is where the checkpoint is, not a name a client can ask for — asking by it
        gets a 404 that lists the aliases this serve does accept. The base URL above is the address this
        browser reached the serve on, not what a sidecar dials internally, so it pastes correctly on the
        machine you are sitting at. The API key is never printed here: if the serve has one, name it in the
        environment.
